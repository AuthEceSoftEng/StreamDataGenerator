## 🎯 Target Variable

- **Name**: `loanapproval`
- **Type**: Binary
- **Description**: Loan Approval
- **Formula**: `(loan <= 20 * salary + 0.5 * commission) and (loan <= 0.7 * housevalue) and ((age < 20 and salary + 0.5 * commission >= 20000) or (age < 40 and salary + 0.5 * commission >= 25000) or (age < 60 and salary + 0.5 * commission >= 30000))`

### Target Drift

- **Drift Type**: changeformula
- **Drift Formulas**:
  - **crisis**: `(loan <= 10 * salary) and (loan <= 0.5 * housevalue) and ((age < 20 and salary >= 30000) or (age < 40 and salary >= 40000) or (age < 60 and salary >= 50000))`
  - **growth**: `(loan <= 50 * salary + commission) and (loan <= 0.9 * housevalue) and ((age < 20 and salary + commission >= 10000) or (age < 40 and salary + commission >= 15000) or (age < 60 and salary + commission >= 20000))`

### Basic Usage

```python
from loandatasetstreamgenerator import LoanDatasetStreamGenerator

# Initialize generator
gen = LoanDatasetStreamGenerator(seed=value)

# Generate samples
for X, y in gen:
    print(f"Features: {X}, Target: {y}")
    # Process your data here
```

### Generate N Instances

```python
# Generate 1000 instances
instances = list(gen.get_n_instances(1000))

# Extract features and targets
X_data = [x for x, y in instances]
y_data = [y for x, y in instances]
```
